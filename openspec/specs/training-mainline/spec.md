# training-mainline Specification

## Purpose

为论文工具策略研究保留清晰的 SFT 到 GRPO 训练主线，明确受支持的入口、模型交接和当前源码的配置传递契约。工程重构仅依赖仓库内材料，不猜填历史有效参数或承诺历史复现，也不将安装、资源策略与独立训练算法混为一谈。

## Requirements

### Requirement: 受支持的训练与运行入口

系统 SHALL 仅将 SFT、GRPO 和文本 ReAct 运行方式作为活动主线，不主动替换为另一种损失或训练算法。系统 MUST 移除 DPO、OPD、PPO、自进化编排、独立 VLM 后训练、算法变体选择、Jev、MCP/Skill CLI 及 Web 服务的活动入口，不保留可被默认命令触发的隐藏旁支。

#### Scenario: 使用主线入口
- **WHEN** 用户查看训练、普通推理或正式评测的帮助与活动文档
- **THEN** 可用入口围绕 SFT、GRPO 与 ReAct 组织，不再要求选择已退出的算法、Agent 架构或启动 Web 服务

#### Scenario: 使用已退出的入口
- **WHEN** 用户尝试使用已移除的算法或服务入口
- **THEN** 该入口不可运行，迁移文档明确其退出范围和受支持的替代路径，不静默转为另一种算法

### Requirement: 仓库内配置基线与传参保全

系统 MUST 在删除算法变体选项前记录当前仓库主线路径的显式算法参数、默认值和传递条件，并在保留路径中维持这些语义及既有奖励公式。未设置字段继续委托训练库的边界 SHALL 被明确记录，不因删除选择入口而猜填损失、重要性采样或奖励归一化值。历史有效参数无法从仓库确认时 MUST 保持未知；工程重构 SHALL 不以补齐外部历史材料为前置条件，也不据源码传参一致宣称历史实验等价。已明确的模型路径、任务选择和轮数修正 MUST 单独记录，不能混称为全部默认行为未变。

#### Scenario: 当前字段未设置
- **WHEN** 当前主线路径对某算法字段保留未设置状态并省略向训练库传入该参数
- **THEN** 重构保持省略行为，基线标注其为库委托值，不将空值或猜测值记录为已解析的有效参数

#### Scenario: 显式配置传递
- **WHEN** 当前保留路径显式指定算法、优化或训练保护参数
- **THEN** 重构后的主线保持对应数值和传递条件，不被变体清理或兼容处理静默改写、遗漏

#### Scenario: 仓库没有历史完整配方
- **WHEN** 已有记录不能确认历史有效参数或依赖版本
- **THEN** 报告注明未知及其证据边界，仍可按当前源码基线完成工程重构，不要求获取外部 manifest，也不宣称历史等价

### Requirement: 运行配置可追溯

每次实际训练 SHALL 保存源码配置基线标识、请求配置、运行时解析的有效值及可获得的派生值、实际依赖版本、模型与数据来源、任务切分、随机种子、运行时及上下文协议版本。无法取得的字段 MUST 标注未知，不伪造历史值；实际覆盖参数 MUST 被记录并形成可区分的运行指纹，不覆盖原基线记录，也不将资源配置变化伪装成完全相同的实验。本次 SHALL 实现这些记录能力，但不要求为验收启动训练或产生新训练 manifest。

#### Scenario: 显式修改运行参数
- **WHEN** 用户调整批量、精度、QLoRA 或其他受支持的运行参数
- **THEN** 产物记录调整后的有效值及与源码配置基线的差异，原基线记录保持不变

#### Scenario: 训练结束或提前停止
- **WHEN** 训练生成最终产物
- **THEN** manifest 同时记录请求步数、实际步数、停止原因和启用的保护设置，不能仅用“训练完成”掩盖提前终止

### Requirement: SFT 到 GRPO 的直接模型交接

系统 SHALL 允许 GRPO 直接消费 SFT 产物及其 manifest，不要求中间 DPO 阶段。全参产物与适配器产物 SHALL 使用明确的模型加载契约；模型或必要元数据缺失时 MUST 报错，不静默退回其他本地模型或远程 API。

#### Scenario: 加载 SFT 适配器产物
- **WHEN** GRPO 的输入是包含基座模型信息的有效 SFT 适配器产物
- **THEN** 系统按其元数据加载正确基座与适配器，并在 GRPO 产物中记录实际来源

#### Scenario: 指定的模型不存在
- **WHEN** 用户指定的训练模型路径或必需文件不存在
- **THEN** 训练在采样前失败并给出缺失项，不触发外部 API 推理或更换训练起点

### Requirement: 主线依赖与工具能力分离

核心训练和离线评测 SHALL 不依赖 Web、数据库、SSE、MCP 或 Jev 服务。系统 SHALL 分别提供 API 基础运行、本地模型推理和 SFT/GRPO 训练的安装层级，基础安装 MUST 不强制安装本地模型或训练栈，本地推理安装 MUST 不强制安装训练器和训练数据处理组件，训练安装 SHALL 包含其所需的本地推理能力。系统 SHALL 保留外部 LLM API 推理、真实 PDF 翻译、图表工具现有推理后端及其明确声明的可选依赖；缺少某个可选依赖时 MUST 在使用相应能力时给出明确错误和安装指引，而不是让工具注册静默缩水。依赖重组 MUST 保持现有版本约束及算法接口保护，不借安装分组升级、降级或替换训练实现。

#### Scenario: 最小研究环境
- **WHEN** 环境没有安装 Web、数据库、MCP 和 Jev 相关组件，且已安装请求操作对应的依赖层级
- **THEN** SFT、GRPO、普通 ReAct 命令和离线评测按各自能力加载受支持入口，工具注册检查仍覆盖全部 10 个工具

#### Scenario: 请求未安装依赖的在线工具
- **WHEN** 用户显式执行需要可选依赖的真实翻译或图表推理
- **THEN** 系统要么执行对应真实工具，要么报告该依赖缺失及安装方式，不返回伪造的成功产物

#### Scenario: 只使用外部 API 与历史记录
- **WHEN** 用户仅安装基础能力，使用 API 推理入口或读取已有轨迹进行重评分
- **THEN** 系统不加载本地模型或训练依赖，10 个工具的业务声明仍完整；真实工具的可选后端只在被明确使用时检查依赖

#### Scenario: 本地推理缺少训练组件
- **WHEN** 用户安装本地推理能力但未安装训练组件，选择已有的本地模型推理后端
- **THEN** 本地推理不会为了导入训练入口或训练回调而要求安装训练器；若随后请求训练，系统在训练开始前说明缺失依赖，不改用远程 API

### Requirement: 可安装包与统一命令入口

系统 SHALL 以可安装的 Python 包提供唯一受支持的 `agentic-arxiv` 命令族，覆盖普通 ReAct、任务 rollout、数据准备、SFT、GRPO、评测和现有诊断能力。安装后的使用 MUST 不要求用户修改 Python 搜索路径或切换到特定源码子目录。旧命令与旧导入命名空间 SHALL 退出受支持接口，迁移说明 SHALL 给出对应的新入口；不提供旧入口兼容保证。命令重组 MUST 保持对应业务操作的默认参数、配置优先级、执行模式、输出内容与失败条件，除规格明确声明的命令名、安装方式和工作区路径规则变化外，不引入算法或业务语义变化。

#### Scenario: 从非源码目录使用安装包
- **WHEN** 用户已安装包，在其他工作目录查看命令帮助或执行具有明确输入路径的操作
- **THEN** 命令能够解析和加载受支持能力，不依赖仓库源码目录进入 Python 搜索路径，也不从安装位置猜测研究资产所在目录

#### Scenario: 查询未安装训练依赖的帮助
- **WHEN** 用户仅安装基础能力并查看根命令、SFT、GRPO 或本地推理相关子命令的帮助
- **THEN** 系统显示用法和所需安装层级，不加载模型、执行工具、读取研究数据或因未安装训练依赖而中断帮助

#### Scenario: 迁移旧操作
- **WHEN** 用户依据迁移说明将旧操作及其配置改为新命令
- **THEN** 对应操作仍保留原有工具能力、任务选择、在线或离线默认、训练参数传递和结果交付；原命令字符串不被偷偷改写成另一种操作或算法

### Requirement: 显式工作区与资产路径

系统 SHALL 区分安装包内的默认配置与用户工作区内的输入和输出。用户 SHALL 能显式指定工作区；未指定时以当前工作目录为工作区。用户传入的相对配置、模型、数据、快照和输出路径 SHALL 相对于该工作区解释，绝对路径保持原义。默认训练配置的有效内容 MUST 与迁移前一致，研究资产 MUST 不随安装包复制、下载或合成。缺失输入 SHALL 报告实际解析路径，不自动搜索其他仓库、使用不同模型或联网补齐。

#### Scenario: 相同工作区从不同目录调用
- **WHEN** 用户在两个不同目录指定同一工作区和相同相对输入路径
- **THEN** 系统解析到同一输入，包的安装位置不改变默认训练配置或数据、模型和产物的归属

#### Scenario: 离线工作区缺少快照
- **WHEN** 用户请求离线操作，但指定工作区没有所需快照
- **THEN** 系统报告缺失快照的解析位置并失败，不从源码目录回退读取、不调用在线工具，也不创建替代快照
