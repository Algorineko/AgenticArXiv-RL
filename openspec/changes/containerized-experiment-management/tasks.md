# Tasks

以下任务按实际实现与验证证据更新。2026-10-15 本轮仅获本地实现与工程验证授权，不操作服务器或启动真实训练；实际训练镜像构建与最后一组真实门禁不能因工程回归通过而提前勾选。检查结果与剩余边界见 `docs/containerized-experiment-validation.md`。

`design.md` 的 Open Questions 仅涉及构建实例和运行输入，不改变架构：实际镜像摘要/依赖闭包在构建时核验，服务器状态在授权部署时核验，正式数据和预算由具体配方提供。输入缺失时按规范拒绝，不以猜测值补齐。

- [x] 5.4 实现严格恢复差异检查，限定相同输入、镜像、设备/rank、训练配置和总预算，只放行操作性目录/尝试字段差异；验证变更卡数、batch、seed、预算、数据或损坏文件均在优化前失败。
- [x] 5.5 为本组增加控制元数据/文件事务回归、固定依赖接口检查及 checkpoint 格式文档；验证不通过伪造模型/轨迹证明真实恢复，旧训练配置与非受管入口仍通过原回归。
