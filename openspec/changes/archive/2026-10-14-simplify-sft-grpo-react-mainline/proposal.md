# Proposal

## Why

项目已经具备直接从 SFT 进入多轮 GRPO 的研究主干，但额外训练路线、三套 Agent 接入方式和 Web 服务层增加了维护成本；训练、推理与专家数据生成之间还存在 ReAct 解析、状态和上下文格式差异。需要在保留现有 10 个工具、86 条扩展任务及可信评测资产的前提下收敛工程，并将工程变化、交互协议变化与算法变化分开归因。

## What Changes

- 将受支持的训练主线收敛为 SFT 和 GRPO，GRPO 直接消费 SFT 产物；训练、采样与评测均采用文本式 ReAct。
- 以当前仓库的源码、配置和已有记录为基线，保全主线路径的显式算法参数、默认值及参数传递语义，包括未设置字段继续委托训练库的边界；不借清理切换为原始 GRPO 损失。历史有效值无法确认时保持未知，不要求补齐仓库外 manifest、启动记录或依赖版本，也不宣称与历史实验等价。
- **BREAKING** 删除 DPO、OPD、PPO、自进化编排、独立 VLM 后训练和 GRPO 变体选择入口；保留 QLoRA 等资源策略及图表工具本身的推理能力。
- **BREAKING** 删除 Jev 路由、MCP/Skill CLI、Web 前端、HTTP 服务、MySQL、SSE 与异步服务编排，收敛安装、命令行入口、配置和活动文档。
- 提取共同 ReAct 契约与每轨迹环境，统一动作解析、任务初始化、论文引用状态、工具结果展示、轨迹和终止原因；保留专家数据生成、普通推理和 GRPO token 采样各自必需的薄适配层。
- **BREAKING** 将解析失败误记完成、离线 fallback 污染状态、翻译状态不一致等修正作为可追踪的运行时语义版本；将统一多消息上下文作为独立协议阶段，改造数据生成与训练适配代码，但本次不生成或重生成 SFT 数据，不新增行为 fixture，不宣称旧 checkpoint 无损兼容。
- 保留全部工具业务参数和注册顺序、86 条 TaskSpec、已有切分、奖励公式与失败上限、语义判定、快照、轨迹隔离、坏例回放和训练信号诊断。历史数据、模型和实验报告不在删除范围。
- 将 Canary、StageVerifier、benchmark、rollout 和语义 oracle 接入一致的任务执行契约；奖励读取实际轨迹，不重新执行工具或合成虚假 FINISH。
- 分阶段验收：先记录仓库内基线，再清理旁支、统一运行时语义与上下文代码。使用源码检查、现有可运行测试、已有记录的解析/评分兼容性及工具/任务/切分定义核对；等价结论只覆盖实际检查到的输入和路径。本变更不包含损失函数替换、奖励重设计或任务缩减。
- **本次仅依赖当前仓库，不新增合成测试数据。** 不合成论文、快照、模型响应、轨迹或数据集；既有单元测试 mock 仅用于原有回归，可适配接口但不扩充造数，不作为真实环境证据。
- 不要求补齐外部研究资产、真实 tokenizer、完整 86 任务执行、SFT/GRPO 训练或模型性能对照。保留相关功能与后续命令，资产依赖检查明确列为本次未验证，不作为未完成任务；当前可运行检查仍须通过，不能用范围豁免掩盖重构引入的失败。完成结论仅限工程重构，不包含历史配方等价、真实 tokenizer 集成、训练效果或模型能力。

## Capabilities

### New Capabilities

- `training-mainline`: 定义仅含 SFT 与 GRPO 的受支持入口、当前源码配置与传参保全、依赖边界、模型交接、运行配置记录和旁支退出要求。
- `react-runtime`: 定义文本 ReAct 的动作、状态、初始化、观测、终止、隔离、上下文版本及训练适配契约。
- `research-validation`: 定义工具与任务资产保全、训练切分隔离、共享评分、多轮验证功能，以及仅使用仓库内现有材料、不训练不造数的工程验收边界。

### Modified Capabilities

无。当前项目没有既有主规格；上述能力将首次形成可执行验收的规格，而不是将现有业务功能视为新增功能。

## Impact

- 训练与运行时：`AgenticArxiv/rl/`、`AgenticArxiv/agents/`、`AgenticArxiv/models/`、`scripts/` 中的数据生成入口及共享工具调用边界。
- 删除范围：额外算法模块、`AgenticArxiv/routing/`、`AgenticArxiv/mcp_protocol/`、`AgenticArxiv/skill_cli/`、`AgenticArxivWeb/`、`AgenticArxiv/api/`、`AgenticArxiv/services/`、数据库实现及 `bin/` 中的服务启停脚本。
- 验证与开发入口：`AgenticArxiv/benchmark/`、相关测试、`eval/`、依赖文件、`Makefile`、CI 与三语 README；混合测试仅删除退出功能对应部分。
- 兼容性：外部 LLM API 客户端与普通 CLI 保留，现有 Web/MCP/Jev 调用入口停止受支持；历史轨迹通过版本化读取处理，不要求继续运行已删除的架构。
- 研究资产：历史记录参考 `data/splits/v6_grpo_train.json`，86 条任务定义与切分参考 `data/splits/v7_86.json`，两者不能混称为同一训练切分。仅索引和核对仓库已有源码、配置、manifest、报告及轨迹；缺少默认快照、实际 SFT JSONL、模型、完整训练 manifest 或 tokenizer 不阻止本次工程验收，不下载补齐、不从摘要重建输入、不用合成材料替代。今后实际运行缺少输入时仍须明确失败，不能自动联网、换模型或伪造结果。
