# Tasks

按 `design.md` 的 S0/S1/S2/S3 顺序实施。第 2、3 组涉及算法选项的删除须先完成 1.1 的当前源码配置核对，不等待仓库外历史证据；S2 有意修正与 S1 工程清理分开记录。

所有任务遵守同一验收边界：仅使用当前源码、配置、任务/切分定义、已有测试和记录；不新增合成论文、快照、响应、token 序列、轨迹、行为 fixture 或数据集。既有 mock 和输入可用于原有回归、适配接口或新增断言，但不扩充造数。下列测试按 S0 确认的可运行范围执行；没有现成输入或依赖的动态检查记录为本次未验证，代码迁移和无需额外输入的源码核对仍须完成，不能借此跳过重构引入的失败。

本次不生成或重生成 SFT 数据，不补齐外部研究资产/真实 tokenizer，不执行完整 86 任务回放、SFT/GRPO 训练（包括少量步数冒烟）或模型性能对照。保留对应功能及后续命令，但这些运行不作为遗留必做项；完成结论只覆盖工程重构，不代表历史配方等价、真实集成或模型效果。
