# 条件式真实模型递归谱系连通性检查（2026-10-31）

这是工程检查，不是方法效果对照。先决条件：已冻结的同 API 批量开发对照正常完成两题、独立回放全部一致，且独立终局成功恰好1/2；0/2或2/2都跳过。尚未看到这两题的完整结果时冻结本协议。仅使用其已公开的训练摘要（任务哈希、成功布尔、停止原因、步数和基础调用计数），不传原始受保护任务、参考解、检查器或最终集给改进器。

同一可用 API 模型和同一计量客户端，最多6次尝试（包括重试）、100k input、8192 output，单次生成不超过1024 tokens、15秒起始间隔。步骤：

1. 使用初始元策略 M0 提交一个元策略候选 M1；记录语法无效、截断、no-op和失败，不重采直到成功。
2. 仅当 M1 语法有效且文本变化时，在共享 `(H, M1, M0, E)` 状态上分别请求 fixed-outer（M0提出）和 recursive（M1提出）两个后续元候选，确认目标与经验哈希相同、提出者来源如协议所述。M1只是临时生成的候选，从未经过性能验收，不可称作改进或已接受。
3. 所有模型请求、响应与候选文本留在私有 cache；公开仅摘要、合法性、是否变化、调用/用量和可追踪哈希。任一API/预算失败如实保留，正常停止，不私自追加预算。

该检查最多证明真实API路径上候选能否被提出、谱系与共同经验是否正确；不运行任务评估、不比较分数、不证明递归更优。需要多条链和独立任务验收的正式RSI协议仍待冻结。
