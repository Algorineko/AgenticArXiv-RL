# 请求前状态反事实探针（推理前冻结）

目标：区分请求前已有下载状态与当前请求动作的混淆。沿用 v1 冻结的真实元数据，只替换 search_dev；train、promotion_val、final_test 原样保留，模型仅评测 search_dev。

12 个任务 = 翻译/显式 force=true 重新下载 × 第1/2/3篇 × 仅列表/列表且已下载。每对请求文本、目标工具参数、论文与预算完全相同，仅 setup 多一次下载。六对只是开发探针，不能当作十二个独立样本推断。

对每个模型运行 baseline 与 state_boundaries。后者仅将已有 history 包入“请求开始前的状态记录”和“本轮请求的动作记录”标签；无动作时标“无”。不添加完成提醒，不读取 gold。固定模型：Qwen2.5-1.5B-Instruct 本机 GPU1；已发布 SFT+GRPO 模型 A40 GPU1。每个模型内部的比较在同一机器进行；跨模型差异混有训练及硬件/软件因素。

这是调用控制探针，不是独立端状态评测。下载/翻译均离线替身；force=true 检验调用参数，替身没有真实网络刷新语义。暂不声称翻译质量、端到端科研能力、RL因果收益或RSI。若出现效果，也只能作为后续验证候选，不能直接晋级。不得根据这轮结果修改标签后重复挑最好成绩。
