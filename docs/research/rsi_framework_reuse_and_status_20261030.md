# RSI 转向与 AgenticArxiv 框架复用说明（2026-10-30）

## 判断

不是完全从零开发，而是重新确立研究问题和证据链，保留 AgenticArxiv 工程基础。先导仍使用 scripts 运行器；现已通过独立适配层实际复用原 ToolRegistry，模型客户端和完整 agent/轨迹框架尚未集成。不能把局部接入写成全面复用完成。不建议为沿用工程而恢复旧任务奖励或旧文本解析约束。

## 已核查的复用边界

| 原模块 | 处置与必要改动 |
| --- | --- |
| `AgenticArxiv/tools/tool_registry.py` | 保留；可实例化独立 ToolRegistry，注册环境代理。注册表本身不执行 JSON Schema 校验，参数验证须在代理边界补齐；避免污染全局 arXiv 注册表。 |
| `AgenticArxiv/utils/llm_client.py` | 保留；兼容 API，extra 可传 native tools。接入前统一限速、逐次重试计费与预算预留，不能让隐藏重试绕过实验预算。 |
| `AgenticArxiv/rl/trajectory.py` | 保留；已有步骤与 JSONL 存取。新协议需补 native tool-call ID、分支/父代、预算、源码摘要、独立终局判定；不要伪造 thought。 |
| `AgenticArxiv/agents/agent_engine.py` | 保留作旧任务入口；ReActAgent 使用文本正则解析且自动注册旧工具。新 RSI 建 native-tool agent/环境适配层，不直接套用这个执行器。 |
| `AgenticArxiv/benchmark/runner.py` | 保留通用运行思路，但当前导入旧任务库和旧成功判定；外部环境必须调用自己的独立评测器。 |
| `AgenticArxiv/rl/self_evolve.py` | 保留诊断、谱系 manifest、验收思路。当前是固定的数据合成/重训循环，不是“改进器递归改写自己”；旧 held-out 诊断方式也不能直接接入锁定最终集。 |
| `AgenticArxiv/rl/train_*.py` 等 | 保留，待 API 阶段出现可迁移收益后审计和接入有限单卡训练。奖励、方差干预、数据隔离与训练预算须重新核查，当前未启动。 |
| 原 arXiv 工具与业务流程 | 保留；可作后续迁移场景。旧已用任务池只作开发/回归，不能再次充当未见验证集。 |
| 旧实验输出与研究叙事 | 从当前 RSI 分支移出，历史 Git 标签保留，不作为新方法证据。 |

目标结构是：原工程工具/模型/轨迹基础设施 → 可替换环境与 native-tool 执行层 → 有版本和预算约束的 solver/harness → 固定或递归 improver → 外部独立评测。模型训练与训练环境课程是后续可选操作；最终评测不随优化过程改变。

## 当前真实进展

- 简单 CPU 开发任务：同一固定基线两遍共 16/16；48 条工具观察独立回放一致。任务已饱和，停止用它证明改进。
- AppWorld 两个已暴露 train 场景：原基线 0/2；官方参考解 2/2，说明环境可解。原基线 24 条观察与最终判定均可回放。
- 固定批量探索提示对照仍 0/2：一项用完 12 步，另一项第 3 次响应超过最多四个并行工具调用而终止。15 条已执行观察回放一致。这个开发对照失败不等于 RSI 方向失败。
- 新候选池按 generator 隔离并排除已暴露组，登记 12/8/8 个训练/开发/锁定最终组。当前只是候选池登记，尚需语义隔离核查和有合理成功率的开发基线；最终池内容未用于调参。
- 尚未完成递归改进器，也没有方法优于固定改进器的结果。下一道门槛是强固定基线能稳定完成一部分非饱和任务，再做等预算递归对照。

## 叙事与投稿定位

研究问题：在模型、历史经验和预算受控时，递归修改改进器，相比固定改进器和固定外层优化器，是否产生可迁移的额外收益，且何时能覆盖获取与验证成本？不能把“加入 RL/TTT/共同进化”本身当作新颖性。

初期冻结 API 模型参数，研究 harness/改进策略；之后才逐项加入有限 RL、训练课程、参数 TTT。API 提示/记忆更新不是参数 TTT，控制器 RL 也不是 LLM 权重 RL。

主目标暂定 ICML 2027，但目前只是基础设施与开发诊断，未达到主会方法论文证据要求。若机制和独立验证尚未成熟，顺延后续合适主会或先投 workshop/技术报告。ICML 2027 截止时间尚未核实，不能按预测日期承诺排期。ICLR 2027 官方投稿截止为 2026-09-25，已过；AAMAS 2027 官方为 2026-10-08，已过。

官方来源：https://icml.cc/ ；https://iclr.cc/Conferences/2027/CallForPapers ；https://warwick.ac.uk/fac/sci/dcs/aamas2027/calls/call-for-main-track/
