# A40 12k 上下文逐级资源检查（2026-10-31）

触发事实：Qwen3-8B 的两个已暴露训练实例均在 8192 输入 token 上限结束，独立回放一致；已执行模型调用的峰值 PyTorch reserved 约19.2 GiB，分配器上限约27.3 GiB。这不是任务能力下界。

只在合适的一张空闲A40上执行合成输入，不加载任务文本或检查器。重新核验模型清单全部文件的字节数/哈希，加载前空闲显存至少40,000 MiB、利用率低于10%；PyTorch分配器上限为物理总显存60%。依次试 4096、8192、12288 个本地token，每次最多生成1 token；强制使用 PyTorch Flash SDP，若不可用直接跳过。每级开始前必须至少剩余12 GiB空闲；使用前两级的额外峰值估算后一级上限，留至少2 GiB分配器余量，不满足时停止，不靠盲目尝试。记录每级实际峰值与停止原因；异常应如实记录，进程退出释放显存。

只有12288级成功、资源界限满足、源码/模型摘要核验通过，才允许未来新一轮将输入上限改为12288。任何后续任务需独立冻结协议并继续标注已经暴露的训练实例；成功通过合成资源检查不代表任务表现更好。不可访问meta-dev或最终任务内容。
