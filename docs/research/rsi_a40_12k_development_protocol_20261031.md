# A40 12k 上下文的训练集诊断协议

条件：仅当独立合成资源检查以 Flash SDP 在同一 Qwen3-8B 模型清单上完成 12288 输入 token、1 输出 token，且无资源错误时执行。合成检查不证明生成 1024 token 的峰值，实际运行继续执行 60% 分配器上限及空闲显存门槛，并对资源不足停止。服务端保持与合成测试相同的 Flash SDP；重新检查模型文件哈希及单卡可用资源。

复用先前已暴露的两个 meta-train / inner-train 实例，保留同一批量工具接口、24 步、128 原子调用和 1024 最大输出 token；唯一预定的运行参数变动是最大输入从 8192 增至 12288，同时强制 Flash SDP 以对应资源检查。上限检查发生于模型调用前，不截断历史。记录终止原因、token、峰值显存和独立回放；训练实例与上下文参数已被观察或调整，不可视为盲测、正式基准或 RSI 效果。若资源门槛不满足则跳过。
